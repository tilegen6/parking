# samples — эталонные payload'ы

Синтетические, но структурно достоверные ANPR-события Hikvision
(`EventNotificationAlert`, namespace `ver20/XMLSchema`).

| Файл | Сценарий | direction | Номер |
|------|----------|-----------|-------|
| `anpr_entry.xml` | въезд | `forward` → ENTRY | 123ABC02 |
| `anpr_exit.xml`  | выезд  | `reverse` → EXIT  | 123ABC02 |
| `real_capture_ipcamtalk.xml` | обезличенная расширенная структура из публичного примера; историческое имя файла сохранено | `forward` → ENTRY | 123ABC02 |

В расширенном примере сохранены XML-структура и ссылка на источник; номер,
адреса устройства, время и идентификаторы заменены демонстрационными.
Примеры не подтверждают испытания на объекте заказчика.

Реальный трафик `capture_server.py` хранится вне отслеживаемых примеров.
В Git добавляются только обезличенные фикстуры после проверки значений и
разрешения на использование данных. Различия прошивок (`picName`, `XID`,
абсолютные/UTC времена, `vehicleInfo`) сначала проверяются на разрешённом
стенде, затем отражаются в parser/контракте и тестах.
