## Как добавить настоящее подтверждение

Добавлять только реально существующий материал с разрешением на такое хранение. Репозиторий сейчас публичный: если документ нельзя опубликовать, хранить его в согласованном закрытом хранилище, а здесь оставить обезличенную сводку и порядок доступа для проверяющего. Наличие закрытого оригинала также нужно подтвердить, а не предполагать.

Карточка каждого доказательства: ID, фактическая дата события, дата записи, источник/роль участника, что подтверждено, согласованный пересказ, связанные требования, разрешённый файл или место хранения и ограничения. Для исправления по отзыву добавлять настоящий PR/коммит после самого замечания. Дата коммита или создания файла не заменяет дату встречи.

Пароли камер, токены, ключи, полные платёжные реквизиты, персональные данные и необезличенные номера/фото автомобилей в этот каталог не помещать. Для доступа к камере достаточно записать, кто и когда получил доступ, каким защищённым способом и прошла ли проверка; значение пароля не нужно.
