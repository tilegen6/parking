### B2. Порядок работ

1. **SEC-1 … SEC-6** — блокируют всё остальное (без них расширяем открытый наружу API).
2. **LOT-1 … LOT-4** — фундамент для экспорта и отчётов.
3. **MAN-1 … MAN-3** — ценность для оператора, MAN-4 ждёт драйвер.
4. **EXP-1, EXP-2 + TZ-X1** — вместе, иначе даты разъедутся.
5. **ANA-1, ANA-2 + TZ-X2**.

Реалистичная оценка: **~3.5–4 недели** одним разработчиком (ТЗ давало 3 недели — не учтены переработка
тестов под auth, 51 фикстура под ParkingLot и ловушки выше).
