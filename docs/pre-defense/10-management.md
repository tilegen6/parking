## Процесс PR и вкладов

Ветка `docs/pre-defense-1-20261020` содержит исходный комплект PR №1; PR слит в `main` 20 октября 2026. Актуальные исправления находятся в `main` и версии `pre-defense-1-r4`. Изменения оформляются отдельными понятными коммитами. PR описывает проблему, результат, проверки и локальный PD-ID; по заданию Git Step 7 ревью другим участником до merge обязательно. Независимое рассмотрение опубликованного комплекта ещё требуется.

На каждом этапе сохраняйте diff, замечание reviewer и исправление, а не только количество коммитов. Для комиссии подготовлен [сценарий демонстрации](13-submission.md). Невыполненные требования фиксируются как открытые, а не «готовые» по наличию файла.
