## Исправления после повторной проверки

- Отчёт CV описан `TypedDict`: вложенные поля доступны без подавления ошибок mypy, формат отчёта/JSON сохранён.
- Остановка потоков CV перенесена с устаревшего `on_event` в FastAPI lifespan; тест подтверждает единственный вызов очистки при shutdown.
- В backend-тестах задаётся отдельный JWT-ключ достаточной длины. Он не предназначен для эксплуатации; production требует собственного случайного ключа в окружении.
- Регулярное выражение даты Kaspi переписано без последовательности, которую Tailwind ошибочно считал CSS-классом. Проверены прежний/новый результат форматирования и отсутствие некорректного CSS в production build.
- Production Compose использует `ghcr.io/tilegen6/smart-parking-{backend,frontend}`, соответствуя CI. Без `PROD_DOMAIN` сборка использует API на том же origin, а не `https://` без хоста.
- Mypy backend и CV является обязательной проверкой CI. SSH-деплой разрешён только при repository variable `DEPLOY_ENABLED=true`; перед подключением проверяются обязательные настройки. До заполнения реальных реквизитов job пропускается. [Порядок настройки](../../deploy/DEPLOY.md).
- Документы отражают уже слитый PR №1 и отличают актуальный `pre-defense-1-r3` от архивных тегов. Фактическое независимое ревью остаётся открытым.

Для тестового окружения закреплён AnyIO 4.14.2, совместимый со Starlette 0.41.3 из текущего FastAPI 0.115.6. Это устраняет предупреждение об alias `anyio.abc.BlockingPortal` при установке свежей транзитивной зависимости; warning-фильтры и изменения сторонних библиотек не использовались. Ограничение нужно снять при обновлении FastAPI/Starlette на версии с актуальным импортом BlockingPortal. Подробности версии — [история AnyIO](https://anyio.readthedocs.io/en/stable/versionhistory.html).

## Проверка материалов

`python scripts/check_submission.py all` проверяет количества источников и рецензируемых работ, таблицы сравнений, ID и связность требований/процедур/сценариев/компонентов, воспроизводимость SVG/DOT, HTML-якоря и локальные ссылки. Проверка credential-паттернов имеет положительный контроль; это не полный аудит безопасности.

Макет и схемы не изменялись. Их браузерная проверка покрывает девять состояний, шесть ссылок навигации, успешную и ошибочную mock-оплату, desktop 1440×1000 и mobile 390×844, отсутствие горизонтального переполнения страницы и ошибок JavaScript. Это проверка автономного макета, не настоящее тестирование с пользователями.

## Границы подтверждения

Docker Engine недоступен локально, поэтому Compose startup/health и реальный PostgreSQL/MinIO/Redis smoke не выполнены. SQLite/API-тесты используют подмены интеграций; они не подтверждают restore, аппаратную безопасность, реальный Kaspi или качество CV на объекте. Адрес VPS, домен и SSH-ключ для фактического деплоя пока не предоставлены. Отзыв руководителя, доступ комиссии, клиентское подтверждение и независимое командное ревью требуют реального участия людей; для них есть [план оценки](09-evaluation.md) и [открытые работы](10-management.md).

Фактический статус GitHub Actions сверяется после push отдельно от локальных результатов. Успешный build образов не объявляется успешным запуском сервера.
