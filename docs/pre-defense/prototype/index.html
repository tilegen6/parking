Действия оператора

Проверить исходный снимок в разрешённом рабочем контуре, связанное событие и направление; исправление — отдельное действие с причиной и аудитом. Здесь снимок намеренно не содержит реальных данных.

Показать ожидаемый аудит ручного исключения

actor: synthetic-operator; reason: визуальная проверка; old/new value; timestamp со смещением; event ID. Это схема записи, не фактическое действие.

Порядок диагностики

  1. Проверить время последнего события, сеть и статус источника.
  2. Не выдавать недоставленное событие за успешно обработанное.
  3. Восстановить источник; replay выполнять контролируемо с проверкой дублей.
  4. Restore испытывать на отдельном стенде, сверив события и снимки.

Автоматический durable spool — целевое улучшение. Этот экран не утверждает наличие готового offline-контура.
