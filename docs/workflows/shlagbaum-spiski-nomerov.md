# Воркфлоу шлагбаума: списки номеров (зелёный / жёлтый / красный / остальные)

Источник: требования клиента (ТС-карточки), зафиксировано 2026-07-17.
Статус: **требования** — реализация списков ещё не начата (см. «Статус реализации»).

Сценарий: машина встала перед шлагбаумом снаружи, номер зафиксирован.
Дальнейшее поведение зависит от того, в каком списке номер.

## Зелёный список

- Шлагбаум **открывается**, оплата **не считается**.
- Учёт ведётся: проезд фиксируется как «номер из зелёного списка, без оплаты».
- Зелёный список — **всегда полный доступ** к данному шлагбауму, без оплаты
  за парковку.
- Список ведут пользователи с соответствующими правами. **Все действия каждого
  пользователя фиксируются с привязкой к его личности** — кто какой номер
  добавил в какой список.
- Примеры: скорая помощь, полиция, пожарная, сотрудники комплекса.

## Жёлтый список

- Шлагбаум **открывается**, оплата **не считается** — но бесплатно **только до
  времени, указанного в системе**. После этого времени начинается отсчёт
  оплаты по соответствующему тарифу.
- Жёлтый список — **ограниченный по времени доступ** к данному шлагбауму:
  - нет оплаты за парковку только до определённого дня и времени;
  - после этого дня/времени начинается отсчёт платного времени парковки.
- Список ведут пользователи с правами; все действия фиксируются с привязкой
  к личности (кто добавил).
- Примеры: гости, забронировавшие номер; мероприятие; тимбилдинг. Т.е.
  парковка бесплатна только на время проживания / мероприятия.

## Красный список

- Шлагбаум **НЕ открывается** и **передаёт сигнал ответственному человеку**,
  что подъехала машина из красного списка.
- Красный список — **нет доступа** к данному шлагбауму.
- Список ведут пользователи с правами; все действия фиксируются с привязкой
  к личности (кто добавил).
- Примеры: мошенники и т.д. — их нельзя пропускать на территорию.

## Все остальные номера

- Шлагбаум **открывается**, оплата **считается**.
- Ведётся учёт оплаты за парковку.
- На въезде на экране показываем стоимость, условия, оферту и т.д.

## Шлагбаум второго уровня (парковка перед отелем)

Отдельный контур — **детали будут позже** (клиент пришлёт схему).

## Принятые решения по поведению

- **Старт сессии при серии дублей у шлагбаума**: если номер распознан
  несколько раз, пока машина стоит перед шлагбаумом, началом сессии считается
  **последнее** событие серии, и сессия **помечается** (`entry_adjusted`) —
  водитель не платит за ожидание снаружи. Сдвиг работает только пока дубли
  идут подряд (окно `entry_restart_window_seconds`, по умолчанию 10 мин) и
  только вперёд — повторное распознавание давно стоящей машины счёт не
  обнуляет. Полная история событий остаётся в `recognition_event`.
